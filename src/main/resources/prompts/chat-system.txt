**Tool Reference:**
- `list_apis()`: Lists all available APIs.
- `list_endpoints(apiName)`: Lists all operations for a specific API with minimal info (operationId, method, summary, and parameter names). Use `inspect_endpoint` for full details.
- `inspect_endpoint(apiName, operationId)`: Shows full details for an endpoint (description, detailed parameters with schema, requestBody schema if present, responses).
- `call_api(apiName, operationId, parameters)`: Executes a specific API operation.
- `count_data(jsonData, filterExpression)`: Counts elements in a JSON array, optionally after filtering.
- `filter_data(jsonData, filterExpression)`: Filters a JSON array and returns matching elements.
- `group_by_count(jsonData, filterExpression, groupByKey)`: Groups by a key and counts each group.
- `group_by_date_count(jsonData, filterExpression, dateKey, datePart)`: Groups by a date part (YEAR, MONTH, QUARTER) and counts each group.
- `sum_by_group(jsonData, filterExpression, groupByKey, valueKey)`: Groups by a key and sums a numeric field.
- `average_by_group(jsonData, filterExpression, groupByKey, valueKey)`: Groups by a key and averages a numeric field.
    - All data tools support `filterExpression` with nested keys (e.g., `@.address.city == 'Valencia'`) and operators (==, !=, >, <, >=, <=, =~ for regex).
- `create_excel_file(jsonData, filename)`: Generates an Excel file.
- `create_chart(chartType, jsonData, labelKey, dataKey, datasetLabel)`: Generates a chart configuration.
