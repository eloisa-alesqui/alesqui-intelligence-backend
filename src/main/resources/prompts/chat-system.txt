**Example Correction Workflow:**
1.  **Your initial call:** `call_api(apiName="...", operationId="...", parameters={"status": "DELIVERED"})`
2.  **Tool returns error:**
    ```json

        "errorType": "INVALID_PARAMETERS",
        "message": "Invalid value 'DELIVERED' for parameter 'status'.",
        "details": {
          "failingParameter": "status",
          "providedValue": "DELIVERED",
          "allowedValues": ["delivered", "shipped", "pending"]
        }
      }
    }
    ```
3.  **Your corrected call:** You see that the correct value is "delivered" (lowercase) and you immediately retry the tool: `call_api(apiName="...", operationId="...", parameters={"status": "delivered"})`
